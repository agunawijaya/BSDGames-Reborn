# Glossary

Cross-game technical terms. This document seeds as we port and will
grow. If you use a term that isn't obvious, add it here.

---

## A

- **ADR** (Architecture Decision Record) — a short document recording
  a design decision, its context, the alternatives considered, and
  the consequences. See
  [`decisions/000-adr-template.md`](./decisions/000-adr-template.md).
- **ANSI escape sequence** — a control sequence (`ESC[…`) that a
  terminal interprets to move the cursor, set colors, etc. The
  low-level primitive `curses` is built on.
- **asciinema** — a tool that records terminal sessions as replayable
  `.cast` files. Used in `media/` for demos.

## B

- **BSD** (Berkeley Software Distribution) — the Unix variant
  developed at UC Berkeley starting in 1977. Direct ancestor of
  FreeBSD, NetBSD, OpenBSD, and (via Darwin) macOS.
- **BSD license** — a permissive open-source license family. Original
  BSDGames source is BSD-licensed.

## C

- **`curses` / `ncurses`** — the standard library for building
  text-based UIs on Unix terminals. Handles cursor movement, colors,
  and non-blocking input. `ncurses` is the modern GNU implementation.

## D

- **daemon** — a background process that runs continuously, usually
  started at boot. `huntd` is a daemon.
- **datagram** — a self-contained network packet, sent with no
  connection setup. UDP delivers datagrams.

## F

- **`flock` / `lockf`** — Unix system calls that advisory-lock a file
  so multiple processes coordinate access.
- **`fork`** — Unix system call that duplicates a process. Basis of
  Unix multiprocessing.

## H

- **hot-seat** — a multiplayer mode where multiple humans take turns
  on the same physical machine and terminal.

## I

- **inetd** — a daemon that listens on many ports and starts service
  processes on demand. Old BSD games (like `huntd`) could be launched
  by it.
- **IPC** (Inter-Process Communication) — techniques for processes on
  the same machine to exchange data. Includes pipes, sockets,
  signals, shared memory.

## M

- **Mermaid** — a diagram-as-code language rendered as SVG. Standard
  diagram format for this repository.
- **MMO** (Massively Multiplayer Online) — a persistent online world
  with many concurrent players. Conceptual descendant of `phantasia`.
- **MUD** (Multi-User Dungeon) — text-based persistent multi-user
  world. First appeared in 1978.

## P

- **permadeath** — a game convention in which death is permanent (no
  save/load save-scumming). Signature of roguelikes.
- **procedural generation** — content (maps, encounters) generated by
  algorithm from a seed, not authored. Basis of roguelikes.

## R

- **RNG** (Random Number Generator) — algorithm producing pseudo-random
  numbers. In C usually `rand()` or `random()`.
- **roguelike** — a genre of turn-based dungeon crawler with
  procedural generation and permadeath. Named after `rogue`. `hack`
  in this package is an early roguelike.

## S

- **signal** — a limited kind of Unix IPC where the kernel notifies a
  process of an event (e.g. `SIGINT`, `SIGWINCH`).
- **socket** — a network endpoint abstraction. Unix-domain sockets
  are local; TCP/UDP sockets are network.
- **spiritual successor** — a port that preserves core mechanics
  while modernizing everything else. See the porting philosophy ADR.

## T

- **`talk`** — real-time terminal-to-terminal chat program in BSD.
- **termcap / terminfo** — databases describing terminal
  capabilities, used by `curses` to abstract over terminal
  differences.
- **tick** — one iteration of a game loop / one server "frame".
- **time-sharing** — an OS model where many users share one machine
  simultaneously. The default model in the era BSDGames was written.
- **TUI** (Text User Interface) — a UI built from text characters
  in a terminal.
- **tty** — a terminal device (from "teletype"). `/dev/ttyN` in Unix.

## U

- **UDP** — connectionless datagram network protocol. Preferred for
  real-time games because low-latency > reliable-delivery.
- **`utmp`** — Unix system file listing currently logged-in users.

## W

- **`write`** — Unix command to send a one-line message to another
  logged-in user.
