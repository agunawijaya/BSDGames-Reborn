# Architecture Decision Records (ADRs) — Fortune

This directory records architecture and design decisions specific to the `fortune`
utility port.

By default, all decisions inherit from the root architecture decisions located at
[`docs/decisions/`](../../../docs/decisions/). ADRs are created here only when this
utility requires an override or a specialized architecture choice (such as UTF-8 string indexing,
alternative database backends, or fuzzy search TUI integration).
