# `ppt` — Lineage

> Where `ppt` sits in the family tree of retro-format utilities.

---

## Direct Siblings (BSDGames)

- `bcd` — punch card format display.
- `morse` — Morse code formatter.
- `banner` — ASCII banner printer.

## Genre Ancestors

- Punched-paper-tape storage and teletype equipment.
- Early data-interchange standards such as ECMA-10.

## Modern Descendants

- Binary visualisation tools.
- Retro-computing demos.
- Educational tools teaching bit representation.
- "Dead media" art projects.

## Influence

`ppt` demonstrates how a simple visual encoding can make binary data tangible. It influenced later tools that render bytes as obsolete physical media.
