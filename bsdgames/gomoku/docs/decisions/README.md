# Decisions Directory

This directory holds Architecture Decision Records (ADRs) specific to
`gomoku` that override or supplement root ADRs.

If no per-game overrides exist, this folder remains empty as per
[ADR-004](../../../../docs/decisions/004-per-game-doc-taxonomy.md).

See root [`AGENTS.md`](../../../../AGENTS.md) §4 for the ADR format
and inheritance rules.
