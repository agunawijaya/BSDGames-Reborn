# `wtf` — Lineage

`wtf` sits at the intersection of command-line reference tools and
internet slang reference works.

---

## Ancestors & Siblings

- **`whatis(1)`** — the Unix man-page one-liner lookup that `wtf` uses
  as a fallback.
- **`apropos(1)`** — broader keyword search in man pages.
- **`dict` / `wn`** — dictionary and thesaurus tools that inspired the
  "ask the computer what a word means" pattern.

## Modern Descendants

- **`tldr-pages`** — community-driven simplified man pages.
- **`cheat.sh`** — cheat-sheet lookup from the command line.
- **Discord/IRC factoid bots** — `?foo` triggers that explain acronyms.
- **Stack Overflow "What does X mean?"** — human-curated expansions.
- **Browser search "X meaning"** — the mainstream, GUI equivalent of
  `wtf`.

## Genre Notes

`wtf` is a **text-transform / reference utility**. It is grouped with
`caesar`, `pig`, `morse`, and `bcd` in the BSDGames package, but its
job is lookup rather than encoding.
