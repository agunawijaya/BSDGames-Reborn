# `countmail` — Lineage

`countmail` is part of the Unix tradition of small, joke utilities that
mock the user's own computing habits.

---

## Ancestors & Siblings

- **`from(1)`** — the mail-summary command that `countmail` uses to
  obtain the message count.
- **`wc(1)`** — the word/line counter used by the script.
- **`banner` / `bcd` / `ppt`** — other text-display toys in BSDGames
  that convert data into theatrical output.

## Modern Descendants

- **Mail client unread badges** — the same information, delivered less
  theatrically.
- **Notification overload jokes** — Slack/Discord bots that announce
  channel message counts.
- **Productivity apps** — inbox-zero counters and unread-triage tools.
- **`fortune`-style mail bots** — programs that read your inbox and
  produce a humorous summary.

## Genre Notes

`countmail` is a **fun / info utility**. It is grouped with `fortune`,
`countmail`, and `pom` in the BSDGames package.
