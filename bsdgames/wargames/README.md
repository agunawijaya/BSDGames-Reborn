# wargames

> **"Shall we play a game?" — the famous BSDGames Easter egg from the movie *WarGames*.**

**Category:** Simulation & Strategy / Easter egg
· **Status:** 🟠 In Progress
· **Original author(s):** University of California, Berkeley (shell script); Joey Hess (man page)
· **First released:** 1993 (script), 1998 (man page)

---

## About This Folder

This folder is the modernised port of **`wargames`** from the original
BSDGames package. It is a self-contained learning artifact — code +
history + design record + technical breakdown.
