# rain

> **A curses screensaver that draws animated raindrops on your terminal.**

**Category:** Screensaver / Demo
· **Status:** 🟠 In Progress
· **Original author(s):** Eric P. Scott
· **First released:** 1980 (3BSD)

---

## About This Folder

This folder is the modernised port of **`rain`** from the original BSDGames package. It is a self-contained learning artifact — code + history + design record + technical breakdown.
