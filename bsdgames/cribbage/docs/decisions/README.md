# Architecture Decision Records (ADRs) — Cribbage

This directory records architecture and design decisions specific to the `cribbage`
game port.

By default, all decisions inherit from the root architecture decisions located at
[`docs/decisions/`](../../../docs/decisions/). ADRs are created here only when this
game requires an override or a specialized architecture choice (such as AI model selection,
pegboard display modes, or network protocol).
