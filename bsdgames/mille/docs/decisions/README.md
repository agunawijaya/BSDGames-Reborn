# Architecture Decision Records (ADRs) — Mille

This directory records architecture and design decisions specific to the `mille`
game port.

By default, all decisions inherit from the root architecture decisions located at
[`docs/decisions/`](../../../docs/decisions/). ADRs are created here only when this
game requires an override or a specialized architecture choice (such as reactive Coup-fourré
networking protocol, card visual design, or 4-player team rules).
