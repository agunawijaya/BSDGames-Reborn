# Architecture Decision Records (ADRs) — Worm

This directory records architecture and design decisions specific to the `worm`
game port.

By default, all decisions inherit from the root architecture decisions located at
[`docs/decisions/`](../../../docs/decisions/). ADRs are created here only when this
game requires an override or a specialized architecture choice (such as tick rate timing,
multiplayer collision resolution, or obstacle maze definitions).
