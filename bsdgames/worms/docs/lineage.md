# `worms` — Lineage

> Where `worms` sits in the family tree of screensavers.

---

## Direct Siblings (BSDGames)

- `rain` — another curses screensaver by Eric P. Scott.
- `banner` — ASCII art generator.
- `snake` — an actual game with a moving snake (related visual tradition).

## Genre Ancestors

- DEC-2136 `worms` — the program that inspired the BSD version.
- Early CRT terminal demos and screensavers.

## Modern Descendants

- `xscreensaver` modules with crawling worms.
- Browser-based snake/worm toys.
- Screensaver and wallpaper engines with particle trails.
- Mobile "snake" games and relaxation apps.

## Influence

`worms` showed how simple agents with memory (the circular body queue) could create engaging, organic motion on text terminals. It is a direct ancestor of both screensaver culture and casual snake-style games.
