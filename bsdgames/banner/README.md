# banner

**Category:** Utility / Display Toy
· **Status:** 🟠 In Progress
· **Original author(s):** Mark Horton
· **First released:** 1980 (3BSD)

## About This Folder

This folder is the modernised port of **`banner`** from the original BSDGames package. It is a self-contained learning artifact — code + history + design record + technical breakdown.
